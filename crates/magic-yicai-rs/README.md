# magic-yicai-rs

第一财经公开新闻列表的有界、只读、元数据适配器。

- 端点：`https://www.yicai.com/news/info/`
- 限制：HTML 2 MiB，嵌入 JSON 512 KiB，最多校验 300 行、返回 50 条
- 节流：同一客户端每次请求开始至少间隔 1 秒
- 时间：来源北京时间按显式 `+08:00` 归一化，保留在记录证据和批次来源时间中
- 准入：`GLOBAL_NEWS_ADMITTED=true`；2026-07-29 两次 live 与三次串行 load 均通过
- 支持：全局新闻首屏元数据正式接口及显式探针
- 不支持：个股新闻过滤、公告、互动问答、历史翻页

适配器只反序列化来源 ID、标题、发布时间、发布方和相对链接；转载内容保留来源原署名。
它不访问文章详情页，不保留摘要、正文、描述、图片或视频，不使用 Cookie、登录、
验证码、订阅或推送端点，也不推断证券身份。公开可技术访问不等于获得内容再分发权，
调用方仍须自行确认使用权。
