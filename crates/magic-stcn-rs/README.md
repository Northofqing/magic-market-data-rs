# magic-stcn-rs

证券时报公开快讯列表的有界、只读、元数据适配器。

- 端点：`https://www.stcn.com/article/list.html?type=kx`
- 限制：JSON 2 MiB，首屏最多校验并返回 30 条
- 节流：同一客户端每次请求开始至少间隔 1 秒
- 时间：配对校验毫秒和秒级来源时间，按显式 `+08:00` 归一化
- 准入：`GLOBAL_NEWS_ADMITTED=true`；2026-07-29 两次 live 与三次串行 load 均通过
- 支持：全局快讯首屏元数据正式接口及显式探针
- 不支持：个股新闻过滤、公告、互动问答、历史游标翻页

适配器只保留标题、规范链接、发布时间和发布方；非空来源署名按原值保留，空来源使用
第一方提供者名“证券时报”。它不访问文章详情页，不保留正文、分享摘要、描述、图片或
视频，不使用 Cookie、登录、验证码、订阅或推送端点，也不推断证券身份。公开可技术
访问不等于获得内容再分发权，调用方仍须自行确认使用权。
